Head de HTML y variables CSS

Aplicaciones Web - Parcial 1 - Tema: Numero 3

1. Metadatos del head

Este documento declara en su <head> el charset, el viewport, dos metadatos de SEO (description y robots), el título y el enlace a estilos.css. No se dibujan en pantalla, pero determinan cómo se interpreta y se muestra la página.

2. Paleta y escala tipográficas

Todos los colores y tamaños de esta página provienen de variables declaradas en :root.

Texto pequeño (--fs-sm)

Texto base (--fs-base)

Texto grande (--fs-lg)

Texto extra grande (--fs-xl)

3. Herencia y alcance

Esta tarjeta usa las variables globales. El recuadro de abajo las redefine solo para él: sus elementos internos heredan los nuevos valores sin tener reglas propias.

Alcance local

Mismo CSS, otro valor de --color-principal.
